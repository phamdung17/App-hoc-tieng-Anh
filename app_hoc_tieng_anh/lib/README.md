# Thư mục lib

Mã nguồn Dart của ứng dụng Flutter. Điểm khởi chạy hiện tại là `main.dart`; mã ứng dụng được chia thành `app/` (khung và điều hướng), `core/` (hạ tầng dùng chung) và `features/` (các tính năng).

Không đặt toàn bộ ứng dụng vào một file. Mỗi tính năng sở hữu UI và logic nghiệp vụ liên quan.
