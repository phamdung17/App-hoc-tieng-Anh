# Đặc tả giao diện 18 trang

Sơ đồ tổng quan thư mục dự án nằm tại [FIleMap.md](../../FIleMap.md). Đặc tả chi tiết từng cụm giao diện nằm cùng thư mục pages của feature sở hữu:

- Giao diện 01–03: [Auth pages](auth/presentation/pages/README.md)
- Giao diện 04–05 và 11: [Learning pages](learning/presentation/pages/README.md); giao diện 06–10 được mô tả ngay trong cùng tài liệu, còn widget triển khai thuộc `learning/presentation/exercises/`.
- Giao diện 12–13: [Scan pages](scan/presentation/pages/README.md)
- Giao diện 14–15: [Vocabulary pages](vocabulary/presentation/pages/README.md)
- Giao diện 16–17: [Review pages](review/presentation/pages/README.md)
- Giao diện 18: [Profile page](profile/presentation/pages/README.md)

Mỗi đặc tả ghi mục tiêu, bố cục, hành vi, dữ liệu/trạng thái và tiêu chí hoàn thành. Các khác biệt FE/BE đã được ghi rõ tại phần liên quan để chốt trước khi triển khai.
