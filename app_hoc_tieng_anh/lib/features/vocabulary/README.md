# features/vocabulary/

Kho từ người dùng đã lưu và chi tiết từ. Bao gồm giao diện 14–15: tìm kiếm/lọc, mức độ thuộc, ảnh, phát âm, ví dụ và ghi chú cá nhân.

## Plugin dự kiến

- `cached_network_image`: ảnh từ trong lưới/chi tiết; xử lý placeholder, lỗi tải và URL ảnh hết hạn.
- `flutter_tts`: phát âm từ chuẩn/chậm mà không cần seed sẵn file audio cho từng từ.
